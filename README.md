# Ejercicios de Punteros Complejos

Repositorio correspondiente a los ejercicios prácticos de gestión de memoria realizados en C++20.

## Descripción

Este proyecto contiene los ejercicios de punteros complejos de la Actividad Colaborativa 2 de la asignatura de Programación con Estructuras Lineales.

Los ejercicios están desarrollados utilizando clases, objetos, atributos y métodos, manteniendo una estructura separada para cada ejercicio.

## Tecnologías utilizadas

- C++
- C++20
- CLion
- CMake
- Git
- GitHub
